# Public evidence

These are selected verification reports, not retail memory dumps. Local workspace/original/user paths were normalized for publication. Hashes inside the reports identify the original files and logs; normalized public JSON has a different content hash.

Missing raw artifacts are intentional. Original game files, BIOS-derived IOP modules, full captured memory, private provider journals and historical build products are preserved locally, outside the public repository. Reports never turn a failed native run or a passing synthetic contract into proof of full-game parity.
